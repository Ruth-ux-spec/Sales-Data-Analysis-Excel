📊 Sales Data Analysis Using Excel

📌 Project Overview

This project analyzes a sales dataset using Microsoft Excel. I cleaned and analyzed the data using Excel Pivot Tables to generate meaningful insights into sales performance, products, customers, orders, payment methods, and referral sources.

🎯 Project Objectives

The main objectives of this project were to:

- Understand overall sales performance
- Analyze sales trends by year and month
- Compare product performance
- Analyze order statuses
- Compare payment methods
- Analyze referral sources and coupon usage
- Identify top customers based on recorded sales

🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Analysis
- KPI Analysis

📈 Analysis Performed

Sales by Year and Month

I analyzed sales, orders, and units sold across different months and years to understand changes in sales performance over time.

Product Performance

I compared products based on orders, recorded sales, units sold, average unit price, and average order value.

Highest recorded sales:

- Chair — 195,620.11
- Printer — 195,612.61

Lowest recorded sales:

- Phone — 151,722.39

Order Status Analysis

I analyzed different order statuses, including Cancelled, Delivered, Pending, Returned, and Shipped.

The cancelled rate was 20.83%, which highlights an area that may require further investigation.

Payment Method Analysis

I compared payment methods based on the number of orders, sales, and average order value.

Referral Source Analysis

I analyzed referral sources to understand where customers came from and the sales generated through each source.

Customer Analysis

I identified the top customers based on recorded sales.

🔍 Key Insights

- The business generated approximately 1.26 million in recorded sales from 1,200 orders.
- Chair and Printer were the strongest products based on recorded sales.
- Phone recorded the lowest sales among the products analyzed.
- The 20.83% cancelled rate is an important area for the business to investigate.
- Monthly analysis can help identify stronger and weaker sales periods.
- Customer and referral-source analysis can help identify valuable sales channels.

💡 Recommendations

1. Investigate the reasons behind cancelled orders.
2. Continue monitoring high-performing products such as Chairs and Printers.
3. Review the performance of lower-selling products such as Phones.
4. Use monthly sales trends to improve inventory and promotional planning.
5. Monitor customer and referral-source performance to identify valuable sales channels.
